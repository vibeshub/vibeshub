vibeshub

Shut down, November 2026

vibeshub has shut down.

vibeshub was a public viewer for AI coding traces, attached to the pull requests they produced. The hosted service is no longer running.

  • Trace links, including the ones in old pull request comments, no longer work.
  • Uploaded traces, digests, and accounts have been deleted.
  • The Claude Code, Codex, and Cursor plugins have nothing to upload to anymore, so you can uninstall them.
  • The source code is still on GitHub, if you want to run your own.

Thank you to everyone who shared a session.
